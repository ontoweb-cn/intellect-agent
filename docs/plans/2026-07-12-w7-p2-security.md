## 3. 锁（S1–S8）

| ID | 锁 | 决议 |
|----|-----|------|
| **S1** | 入口 | `webui/api/workspace_io.py`：`resolve_under_root` / `open_under_root` / `write_under_root`；禁止热路径 `open(resolved_path)` 裸调 |
| **S2** | Containment（**C1**） | 统一策略 = **严格**：`resolved.relative_to(root.resolve())` 必须成功。先修 `safe_resolve_ws` 逃逸分支，再统一；**禁止**把今日「严格 routes」迁到未修补的 ws |
| **S3** | Symlink + open（**I1**） | **允许**指向 root **内** 的 symlink（UX）。Open：**post-resolve** 路径 + leaf `O_NOFOLLOW`（TOCTOU 护栏）。**不是**「拒绝一切 symlink」，也 **不是** 完整 `openat` 漫步 |
| **S4** | 覆盖面 | workspace：read/save/delete/create/rename/mkdir/raw/download/zip walk；`workspace.read_file_content`/`list_dir`；`upload.extract_archive`；`workspace_git` discard/unlink；**`_session_attachment_dir` raw**。reveal/path/vscode = resolve-only 顺带迁移（非内容 I/O） |
| **S5** | Trusted 默认（**R4**） | **Unset → 信任 `127.0.0.0/8` + `::1`**。显式 `none` / 空 allowlist → **不信任何**转发头。Unset ≠ empty |
| **S6** | Helper | `client_ip` / `request_scheme` / `request_host` — peer ∈ trusted 才读转发头 |
| **S7** | 接线 | onboarding（**含 `X-Real-IP`**）、CSRF host（**含 `X-Real-Host`**）、`_is_secure_context`、passkeys、members OAuth scheme |
| **S8** | 非目标 | Journey P1-3；update channels；Gateway restart 契约；全量 `openat`；agent sandbox |

## 4. 实施切片

### 4.1 #1 Anchored I/O

```text
routes / upload / workspace / workspace_git / attachments
        │
        ▼
  resolve_under_root(root, rel)   # strict containment (S2)
        │
        ▼
  os.open(resolved, flags|O_NOFOLLOW) → fd   # leaf guard (S3)
```

Windows：同 containment；无法 `O_NOFOLLOW` 时拒绝仍为 symlink 的路径。

### 4.2 #2 Trusted proxy

```text
peer = handler.client_address[0]
trusted = loopback_default OR parsed CIDRs
if peer in trusted: honor X-Forwarded-* / X-Real-*
else: socket peer + Host only
```
